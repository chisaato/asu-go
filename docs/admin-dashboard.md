# Web 管理后台与任务运维规范 (Admin Dashboard)

本文档定义 ASU-Go 内置管理控制台（Web Admin Dashboard）的设计方案。后台直接集成在单一 Go 二进制内，访问 `http://<server-ip>:8000/admin` 即可直达。

---

## 1. 核心定位与设计目标

原版 ASU 仅有公开的只读统计图（`/stats`），完全缺失运维调度管理能力。ASU-Go 管理后台定位为一个**轻量、高效、开箱即用的固件构建与调度管理中心**，主要满足：
1. **实时可视**：像 GitHub Actions / GitLab CI 一样，毫秒级看到当前任务的实时执行日志与分步进度。
2. **可控运维**：对卡死、异常、过期的任务进行介入（取消、重试、清理孤儿容器）。
3. **存储自治**：清晰掌控构建产物对磁盘的消耗，并提供直观的手动或自动化清理策略。
4. **在线调试**：提供可视化测试页面，管理员无需手机或 LuCI 即可直接在线配置参数并发起构建验证。

## 3. 功能模块详细说明

### 3.1 仪表盘与运行中任务 (Dashboard & Active Tasks)
- **集群与引擎状态**：
  - 显示当前绑定的容器运行时类型（Podman 或 Docker）与版本。
  - 显示 Socket 连接延迟与活跃容器数。
- **活跃任务卡片**：
  - 展示正在构建任务的设备型号、版本、客户端来源（如 `owut/1.2`、`luci/24.10`）。
  - **进度条指示器**：根据 Runner 探测到的阶段（`Init` -> `Manifest` -> `Compiling` -> `Signing` -> `Done`）动态展示进度。
  - **一键终止 (Abort/Kill)**：对任何卡滞任务，管理员点击后调用后台 `/admin/api/tasks/{hash}/cancel`，立即中止构建并释放 Worker 槽位。

### 3.2 任务详情与实时终端 (Live Log Terminal)
- **技术实现**：
  - 前端采用轻量终端模拟组件（支持 ANSI 16 色与粗体语法高亮）。
  - 连接底层 `/api/v1/build/{request_hash}/stream` SSE 接口。
  - 具备 **自动滚动锁定（Follow Log）** 功能：用户向上滚动查阅历史日志时停止自动滚动，滚动到底部时自动恢复实时跟随。
- **构建元数据抽屉**：
  - 展示请求的原始 JSON 参数。
  - 展示从 Makefile 解析出的 Default Packages 与用户额外增加/剔除的 Packages 差集。
  - 展示构建产物清单（文件名、下载链接、文件大小、SHA256 校验和）。

### 3.3 任务历史列表与审计 (Task History)
- **历史归档**：
  - 记录所有排队、完成、失败的任务。
  - 支持按状态过滤（`All`、`Running`、`Success`、`Failed`）。
  - 针对历史失败的任务，点击可直接查看当时的完整 stderr 与截获的上下文日志，定位是“包冲突”、“存储超限”还是“网络拉取超时”。
- **重新构建 (Retry)**：
  - 遇到临时网络失败的任务，支持管理员点击“重试”，无需客户端重新发起请求。

### 3.4 存储与磁盘缓存管理 (Storage Management)
- **存储概览**：
  - 本地产物目录（`/store`）容量展示。
  - 统计当前缓存的不同版本固件总数量。
- **生命周期策略 (TTL Policy)**：
  - 在界面直观展示和调整自动清理规则（如：正式版固件保留 7 天，SNAPSHOT 固件保留 24 小时，失败任务记录保留 2 小时）。
- **手动清理操作**：
  - 支持勾选删除指定任务产物。
  - 提供“一键清理过期产物”与“一键清理构建失败残留”按钮。

### 3.5 手动固件在线构建器 (Visual Builder Tester)
- 为管理员自检和测试提供便利：
  - 级联下拉框：从元数据引擎直接读取当前支持的 `Distribution` -> `Branch/Version` -> `Target` -> `Profile`。
  - 软件包选择器：输入软件包关键词（如 `luci-theme-argon`），支持添加自定义仓库源（Custom Repositories）与公钥。
  - 点击“立即构建”，自动打开终端弹窗展示构建全过程。

## 4. 前端工程与嵌入式分发

为了实现真正的单二进制交付：
1. **轻量技术栈**：采用 Bun + Nuxt 4（SPA 模式，`ssr: false`）+ Nuxt UI v4（Tailwind CSS v4），详见 [tech-stack.md](tech-stack.md)。
2. **嵌入式编译**：
   前端经 `nuxt generate` 编译后产物输出至 `web/dist`，Go 通过 `//go:embed all:dist` 嵌入可执行文件。
3. **免额外代理**：
   Go API 服务同时作为静态文件文件服务器，内置 HTTP 路由直接接管 `/admin` 路径，无需用户再额外部署 Nginx 或 Caddy 处理前端路由。
